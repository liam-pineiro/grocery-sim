simulates a grocery store checkout line

First, the code will prompt the user for a number of customer objects, with an amount of items they will be checking out. Once the user is done adding customers, the code will go through and add each customer to a checkout line based on the number of items the customer has as well as the total wait time of each line, with each customer having a time equal to the number of items they are checking out, trying to make them as similar as possible in wait times. The customers can also be added to an express line if they have a certain number of items.
